# Testų micro-learning: prototipas V.1

Mokesčių Suflerio žinių testų prototipas: atsakymo išaiškinimas rodomas iškart po kiekvieno atsakymo, o pabaigoje lieka bendra suvestinė.

**Peržiūra:** https://richkus.github.io/testu-micro-learning/

- Statinis HTML (Alpine.js + Open Sans), be build žingsnio.
- Kairėje apačioje „Versijos“ ir „Fonas“: prototipo variantų ir fono nustatymų skydeliai.
- Duomenys ir tekstai pavyzdiniai, dizainas dar keisis.
